# 三相异步电动机单向点动与连续运行控制（S7-1200 / TIA Portal V15）

## 任务要求

1. 通过实验理解三相异步电动机**点动**和**连续运行**两种控制方式的区别。
2. 熟悉 PLC 编程，能解决简单的编程故障问题。

## 主电路

三相电源 `L1 / L2 / L3` → 断路器 `QF` → 熔断器 `FU1` → 接触器 `KM` 主触点 → 热继电器 `FR` 发热元件 → 电动机 `M`。

- `QF`：通断电路
- `FU1`：短路保护
- `FR`：电动机过载保护
- `KM` 主触点：控制通电与断电

## 控制电路

| 器件 | 类型 | 作用 |
|---|---|---|
| `SB1` | 常闭 | 停止按钮 |
| `SB2` | 常开 | 点动运行按钮 |
| `SB3` | 常开 | 连续运行按钮 |
| `FR` | 常闭触点 | 过载保护 |
| `KM` | 接触器线圈 | 使线圈得电 |

区别只有一条：**按下 SB2 电动机运行、松开就停；按下 SB3 运行、松开后靠自锁继续转**，
但两者都受 SB1 和 FR 的断电控制。

## 验证

| 操作 | SB1 | SB2 | SB3 | KM | 电机状态 |
|---|---|---|---|---|---|
| 初始 | 0 | 0 | 0 | 0 | 停 |
| 按下 SB2 | 0 | 1 | 0 | 1 | 转 |
| 松开 SB2 | 0 | 0 | 0 | 0 | 停 |
| 按下 SB3 | 0 | 0 | 1 | 1 | 转 |
| **松开 SB3** | 0 | 0 | 0 | **1** | **继续转（自锁）** |
| 按下 SB1 | 1 | 0 | 0 | 0 | 停 |
| 模拟过载（FR 断开） | 0 | 0 | 0 | 0 | 停 |

关键就是「松开 SB3」这一行：输入全回到 0，但 KM 仍然是 1——这一位就是自锁触点在起作用。

## 四条功能验证

1. **点动**：SB2 控制支路**没有引入自锁**，只靠 SB2 自身的通断控制 KM，所以松开就停。
2. **连续运行**：SB3 控制支路引入了 KM 的**自锁触点**，松开 SB3 后靠自锁维持 KM 得电。
3. **停止**：SB1 作为总停止**串联**在控制电路里，能切断所有控制支路的电流。
4. **过载保护**：FR 常闭触点串联在控制电路中，过载时自动断开、切断电路。

## 复盘

1. 编程时要注意逻辑关系，防止出现功能异常；有报错要及时处理，不要带着错继续往下写。
2. 设计的梯形图实现了预设功能，满足电机控制的安全与实用要求。
3. 程序修改灵活：后续要加功能，可以在现有梯形图上直接拓展支路，不用推翻重写。

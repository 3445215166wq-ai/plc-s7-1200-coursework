# 自动配料模拟系统（S7-1200 / TIA Portal V15）

工程文件：[`projects/auto_batching_system`](../projects/auto_batching_system)
运行录像：<https://www.bilibili.com/video/BV1Y6ynzrEJV/>（1 分 9 秒）

## 任务要求

按下启动按钮 SB1 后，模拟汽车进料、装料、装满停止的配料流程：

1. **按下 SB1 启动**：信号灯 L2 熄灭、L1 点亮，表示允许汽车开进装料位置，此时出料阀 D1 关闭。
   若物位传感器 S1 状态为 `0`（料斗未满）则进料阀 D2 开启；若为 `1`（已满）则 D2 关闭。
   电机 M1~M4 此时全部为 `0`。
2. **汽车就位**：限位开关 SQ1 为 `1`，L2 点亮、L1 熄灭；电机 M4 启动，随后 M3、M2、M1 依次启动，
   出料阀 D1 打开，**时间间隔 2 s**。
3. **汽车装满**：限位开关 SQ2 为 `1`，出料阀 D1 关闭，随后 M1、M2、M3、M4 依次关闭，**时间间隔 2 s**；
   同时 L1 点亮、L2 熄灭。
4. **按下 SB2**：系统终止运行。

要求手画 I/O 分配表、外部接线图、顺序功能图，再写梯形图。

## I/O 分配

PLC 变量表里的实名（工程内可查）：

| 类别 | 变量名 | 作用 |
|---|---|---|
| 输入 | `启动` / `停止` | SB1 / SB2 |
| 输入 | `物料传感器` | S1，料斗满 / 未满 |
| 输入 | `限位开关1` / `限位开关2` | SQ1 就位 / SQ2 装满 |
| 输入 | `保护` | 热继电器等保护触点 |
| 输出 | `进料阀T` / `出料阀T` | D2 / D1 |
| 输出 | L1 / L2 | 允许进料 / 就位状态灯 |
| 输出 | KM1~KM4 | 电机 M1~M4 接触器 |

## 实现思路

按「步—动作—转换」的顺序功能图拆成 5 个逻辑步：

```
待机允许进料 → 汽车就位 → 依次启动电机 + 出料 → 装满停止 → 复位待机
```

每一步的**动作**（开哪个阀、启哪台电机、亮哪个灯）和**转换条件**（S1 / SQ1 / SQ2 的哪一个信号）
分开写，不混在一起判。这样后续哪一步不动作，回去看顺序功能图就能定位到是哪个转换条件写漏了。

三处工程上的处理：

- **2 s 间隔**用 TON 定时器串起来，M4 → M3 → M2 → M1 依次启动、M1 → M2 → M3 → M4 依次停止，
  避免四台电机同时启停造成的负载冲击。
- **输出条件打包**：把「就位 + 未装满」这类复合条件先封成中间变量 M，再由 M 驱动接触器输出，
  主程序按功能分块，不写成一长串串联触点。
- **互锁**：停止按钮按下立即终止所有动作；S1 满时关 D2；SQ1 才允许出料、SQ2 才允许停止出料。

## 验证

仿真逐状态核对输入与输出，六个状态全部一致：

| 操作 | 输入状态（I 区） | 输出状态（Q 区 / L 区 / KM 区） | 结果 |
|---|---|---|---|
| 初始待机 | SB1=0 SB2=0 S1=0 SQ1=0 SQ2=0 | D1=0 D2=0 L1=0 L2=0 KM1-4=0 | 全灭，一致 |
| 按下 SB1 | SB1=1 其余 0 | D1=0 D2=0 **L1=1** L2=0 KM1-4=0 | L1 亮，一致 |
| 料位变化（S1 由 0 变 1，料斗满） | SB1=1 S1=1 SQ1=0 SQ2=0 | **D2 关闭**，L1 保持，KM1-4=0 | 一致 |
| 汽车就位（SQ1=1） | SB1=1 S1=1 SQ1=1 SQ2=0 | **L2=1 L1=0，KM4=1**，2 s 后 KM3、KM2、KM1 依次启动 | 一致，时序符合 2 s 间隔 |
| 汽车装满（SQ2=1） | SQ1=1 SQ2=1 | **D1 关闭**，KM1~KM4 依次停止（间隔 2 s），L1 亮、L2 灭 | 一致，时序符合 2 s 间隔 |
| 按下 SB2 | SB2=1 | 全部复位为 0 | 一致 |

## 复盘

1. 写顺序功能图必须严格按步来，每一步的准确性直接决定后面所有转换能不能走通，
   中途跳步或合并步，后面一定会返工。
2. 转换出问题第一时间回去看顺序功能图，绝大多数情况是转换条件写得不严谨，而不是梯形图本身写错了。
3. 状态位各自代表什么必须先想清楚再动手，混淆概念（尤其料位这类互斥信号）是最容易出错的地方。

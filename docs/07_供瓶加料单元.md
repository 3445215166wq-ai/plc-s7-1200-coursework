# 自动化产线 · 供瓶加料单元（S7-1200 + PROFINET + HMI）

工程文件：[`projects/line_bottle_feeder`](../projects/line_bottle_feeder)
五单元联机演示：<https://www.bilibili.com/video/BV1VnyHz5Evj/>（1 分 21 秒）

> 本仓库只收**供瓶加料单元**这一个单元的工程。本文按工程里的程序块名与 PLC 变量表整理。

## 单元在产线里的位置

整条自动化产线分五个单元：颗粒上料 / 上盖拧盖 / 质量检测分拣 / 产品搬运 / 立体入库。
供瓶加料单元负责**把空瓶送上主传输带、并把颗粒料定量取放到瓶口**，做完再交给下游单元。
主站用 S7-1200，单元之间走 **PROFINET** 交换数据，每个单元各自带 HMI 触摸屏。

## 现场设备与 I/O

工程里 PLC 变量表的实名：

| 类别 | 变量名 | 说明 |
|---|---|---|
| 输送 | `空瓶输送带_变频器` | 供瓶输送带，变频器调速 |
| 输送 | `主传输带` | 主传输带 |
| 输送 | `颗粒料传送带` | 颗粒料供料带 |
| 气动 | `升降气缸` | 吸盘升降 |
| 气动 | `旋转气缸` | 取料后旋转到瓶口上方 |
| 气动 | `夹瓶气缸` | 夹紧瓶身定位 |
| 气动 | `推料颗粒气缸` | 推颗粒料 |
| 真空 | `吸盘_电磁阀` | 真空吸盘通断 |
| 传感 | `夹瓶处电眼` | 夹瓶位置检测 |
| 传感 | `空瓶到位` | 空瓶到位 |
| 传感 | `颗粒有无` | 料位检测 |
| 传感 | `末端颗粒到位` | 颗粒送到末端 |
| 定位/计数 | `定位`、`计数` | 工位定位与计数 |
| 按钮 | `开始按钮` / `停止按钮` / `复位按钮` / `上电` | 操作面板 |
| 指示灯 | `开始灯_绿`、`复位灯_橙` | 状态指示 |

也就是说这个单元一共接了 **5 个气动/真空执行元件**（升降、旋转、夹瓶、推料四个气缸 + 真空吸盘电磁阀）
**+ 4 个位置或料位传感器 + 3 条输送带**。任何一个动作都必须等前一个动作的到位信号成立才能走，
所以没法顺序硬写，得拆成步。

## 顺序步

工程里每一步是一个功能块实例，块名就是这一步在做什么，串起来是完整的取放料循环：

| 步 | 块名 | 动作 |
|---|---|---|
| 1 | `辅助器1` | 公共辅助逻辑（上电、总使能） |
| 2 | `下降取物` | 升降气缸下降到位 |
| 3 | `延迟夹瓶` | 夹瓶气缸夹紧，等夹紧确认 |
| 4 | `确保上升` | 确认已上升（防止带料下降时卡住） |
| 5 | `吸住后上升` | 真空吸盘吸住颗粒后抬起 |
| 6 | `解开旋转` | 松开旋转气缸的保持 |
| 7 | `旋转后下放` | 旋转到瓶口上方并下降 |
| 8 | `确保下放成功` | 确认下放到位 |
| 9 | `下放完关闭磁吸` | 关闭吸盘，颗粒落进瓶里 |
| 10 | `循环3次停止` | 计满 3 次后停止循环 |

这里有两个「确保」步（`确保上升`、`确保下放成功`）是故意加的双重确认位：
气动元件动作到位信号有时会抖一下，只用单一位判会跳步，加一步专门确认就稳了。

## 实现要点

- **变频器控制输送带**：空瓶输送带接的是变频器（变量表里就是 `空瓶输送带_变频器`），
  不是直接用接触器通断电机——输送带要能调速，供瓶节拍才跟得上下游。
- **PROFINET 联机**：工程里配了 CPU 1214C 的集成口 `PROFINET 接口_1`，单元与主站之间靠它交换状态。
  联机和单机两种跑法的入口分开，联机时本单元要等主站给信号才动。
- **复位与上电流程**：变量表里有 `上电`、`复位按钮`、`复位灯_橙`，说明做了一套独立的上电初始化
  和复位回路——气缸跑到位之后状态位不会自己回零，必须靠复位把它们拉回初始步，
  否则下一轮从中间某一步开始就会错位。

# 西门子 S7-1200 PLC 课程作业合集

西门子 S7-1200 的课程作业与课程综合设计。全部用 **博途（TIA Portal）V15** 编写，编程语言 **LAD（梯形图）**，
顺序控制类的题目按 **顺序功能图（SFC，「步—动作—转换」）** 的思路组织流程。

一共 7 套课程作业 + 1 个自动化产线的供瓶加料单元。每套都从手画 I/O 分配表、外部接线图、顺序功能图开始，
再写梯形图，最后跑仿真把每一个状态的输入输出逐个对一遍。

## 硬件与软件

| 项 | 内容 |
|---|---|
| CPU | S7-1200 **CPU 1214C DC/DC/Rly** |
| 编程软件 | TIA Portal V15（博途） |
| 编程语言 | LAD 梯形图；流程设计用顺序功能图 |
| 组网 | PROFINET（产线单元与主站交换数据） |
| 仿真 | S7-PLCSIM |

## 用到的指令与做法

- **IEC 定时器**：TP 脉冲、TON 接通延时、TOF 关断延时、TONR 时间累加器，都调用各自的背景数据块（DB）
- **IEC 计数器**：CTU 加计数、CTD 减计数、CTUD 加减计数
- **中间变量 M 打包输出条件**：把「开 5 秒 + 关 3 秒」这类复合条件先封成一个 M，再由 M 去驱动接触器，
  主程序按功能分块，不写成一大坨串联
- **七段数码管段码驱动**（a~g 段）：显示 0~8 与台号
- **自保停与互锁**：正反转互锁、抢答互锁、限位与料位互锁
- **顺序功能图**：用 M0.0~M1.6 做步标志、定时器做「转换」条件

## 关于工程文件

- 用 **TIA Portal V15** 打开对应目录里的 `.ap15` 文件（例如 `projects/auto_batching_system/auto_batching_system.ap15`）。
  版本低于 V15 打不开。
- 工程里只保留程序本身，已清除个人与院校信息。
- `XRef/`、`IM/`、`System/` 都是 TIA 自己的项目数据，不要手动改动。

## 几点说明

- 这些是**课程作业**，题目、I/O 要求由课程给定，不是我自己找的题。
- 有一处超出课程要求的自选动作：四路抢答器做了 **13 个测试用例**，其中「同时按下 1、2 号」的多重触发冲突、
  「复位→开始→抢答→复位→超时」连续 5 轮循环这两条老师没要求，是我自己加的（见 [docs/02](docs/02_四路抢答器.md)）。
- 报告原件没有放进仓库，`docs/` 下是按报告整理并去掉姓名、学号、班级、指导教师、成绩的版本。
